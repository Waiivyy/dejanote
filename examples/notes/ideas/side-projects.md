# Side project ideas

Ideas worth keeping, roughly ranked by how much I would actually use them.

1. Recipe scaler that converts a recipe to any number of servings and to metric, and rounds to sensible kitchen amounts.
2. A plant watering tracker that learns how fast each pot dries out instead of using fixed schedules.
3. Weekend bike route planner that avoids main roads and ends at a cafe or a lake.
4. A tiny dashboard for the flat: next bin collection, tram departures, and the weather for the walk to the station.

Rule: pick one, give it a month of weekends, and only start the next one when it is either finished or deliberately dropped.
